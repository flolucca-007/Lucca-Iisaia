# TP final: Guardia Viva

Trabajo final grupal de la materia Introducción a la Ingeniería de Software Asistida por IA (IISAIA).

Integrantes: Carlos Lugones, Mariano Reimondez y Florencia Lucca.

Guardia Viva es una aplicación web instalable en el celular para gestionar las guardias de un servicio hospitalario de 10 a 12 médicos. Reemplaza el grupo de WhatsApp y la planilla que se usan hoy: los médicos avisan sus ausencias, otros se postulan para cubrirlas y el coordinador asigna con candidatos ordenados por equidad.

Tecnologías: React (PWA), FastAPI y Postgres en Supabase.

Repositorio del proyecto (código, commits, branches y pull requests): https://github.com/reimondezmariano/TP3_IISAIA

Aplicación publicada: https://guardia-viva.onrender.com
